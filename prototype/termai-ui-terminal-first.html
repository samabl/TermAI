Command Explain L0 只读 流式 
kubectl -n payments get pods -l app=payments-api -o custom-columns=NAME:.metadata.name,RESTARTS:.status.containerStatuses[0].restartCount | sort -k2 -nr | head -5
kubectlK8s CLI，命中 trusted subprocess 白名单（AR-07）；以 argv 调用，无 shell -c。
-n payments指定命名空间；非默认 ns 必须显式给出，避免落到 current-context 的 default。
get pods只读列举，无写副作用 → 判定 L0，零摩擦。
-l app=payments-apilabel selector；值来自终端输出（不可信来源），已标注来源并原样传参。
-o custom-columns=…自定义列，避免依赖默认列序被未来版本改动。
| sort -k2 -nr按第 2 列（RESTARTS）数值降序；纯本地管道，不出网。
| head -5只取前 5 行；上游 sort 收到 SIGPIPE 并退出，此处为预期行为。
  • 该命令只读，未命中 AST 危险模式（rm -rf / force push / drop / delete / 提权）。
  • 输出可能含 Pod 名与环境标识（数据分级 L2）→ 默认本地，不进入模型上下文之外的出站请求。
