# ADR-0016：产品视觉语言 v2（Netcatty 取向）与信息密度规则

- 状态：**Accepted**（项目发起人于评审中确认接受；已落地为 HARNESS **AR-22**，取代 DC-10）
- 日期：2025-01-01
- 决策者：项目发起人（提出方向）+ Orchestrator（整理为可执行规则）
- 关联：将取代 **DC-10**（暗底高对比 + 单一冷青 accent）、修订 **docs/spec/02** 视觉语言与交互章节；细化 **DC-03**（三个「会话」的边界）与 **AR-16**（AI 交互范式）。**不改变** AR-01（混合渲染分层）、AR-03（AI 与内核边界）、AR-06（风险与审批）、AR-14（画质）、AR-20（a11y 边界）。
- 实现位置：`prototype/termai-ui-netcatty-style.html`（原型）、未来 `tokens/*.json` 与 `web-shell` 组件库

## 背景与问题

v1 视觉方案（暗底 + 霓虹冷青 + 高信息密度 + 无侧栏）被发起人否决：「我觉得这个 ui 不好看，我喜欢 netcatty 那种风格的」。参照 Netcatty（binaricat/Netcatty，Electron + React 的 AI SSH 客户端）的实际界面后，发起人进一步给出六条具体要求：

1. 风格不统一；2. 布局太挤；3. 较小 UI 不要文字、悬停显示；4. 终端自动换行；5. Agent 跟随会话且支持跨会话操作；6. 减少滚动条。

其中第 4 条与第 5 条**不是纯视觉问题**：前者涉及终端软换行语义，后者涉及 Agent Session 与 PTY Session 的作用域关系（DC-03）。因此需要一条 ADR 同时记录视觉语言与交互规则。

## 可选方案

| 方案 | 描述 | 结论 |
| --- | --- | --- |
| A 保持 v1 视觉 | 暗底霓虹、极密 | 否决（发起人明确不接受） |
| B 直接复刻 Netcatty 外观 | 照搬其布局与配色 | 否决（信息架构不同：它以 Host/Keychain/Proxies 为主导航，我们以 Workspace/Tab/Pane 为主对象；且不应把第三方产品当规格） |
| C 借鉴其视觉语言、按我们的信息架构重写 | 采用 macOS 浮动窗、azure 蓝、卡片化、浅色一等主题；导航与语义仍按 HARNESS | **采纳** |
| D 只改配色，不动布局 | 改动最小 | 否决（未解决"太挤""滚动条多""小 UI 带文字"三条） |

## 决策

### D1 视觉语言（token v2）

| 维度 | 取值 |
| --- | --- |
| 窗口 | macOS 风格浮动圆角窗（圆角 14~18px、交通灯、柔投影）；壁纸仅原型模拟，产品中即桌面 |
| 主色 | **azure 蓝**：深色 `#4A9EFF`、浅色 `#245BC9`；仅用于主操作/选中/焦点/链接 |
| 深色 | 画布 `#08090C`、卡片 `#17191F`、浮起 `#1E2129`、边框 `#2A2F38`、正文 `#E7E9EE`、次要 `#9BA3B0` |
| 浅色 | **一等主题**：画布 `#F6F5F2`（暖米白）、卡片 `#FFFFFF`、边框 `#E6E4DF`、正文 `#1B1D21`、次要 `#616874` |
| 间距 | 单一标尺 4/8/12/16/24/32/48，禁止任意值 |
| 圆角 | 输入 8 / 卡片 10 / 弹层 14 / chip·头像 999 |
| 图标 | 内联 SVG、stroke 1.5、仅 16/20/24 三档；**emoji 只允许出现在 AI 回答正文** |
| 按钮层级 | primary 实心 accent / secondary 描边幽灵 / tertiary 纯图标 / danger 实心红 |
| 对象色 | 彩色仅用于对象身份色块（工作区/主机图标），其余中性灰阶 |
| 动效 | 120/180/240ms + ease，reduced-motion 即时退化 |

### D2 信息密度与留白

卡片 padding ≥16（推荐 20）、卡片间距 ≥16、区块间距 ≥32；UI 行高 1.5~1.6（终端网格保持 1.25）；顶栏次要动作收进「更多」菜单；状态栏高度 ≥28px。

### D3 小 UI 去文字 + 悬停提示

顶栏、卡片操作、状态栏、面板头部、终端状态条上的次要按钮**一律图标化**，禁止可见文字；每个图标按钮必须有 `title` + 自定义 tooltip（延迟 400ms、focus 亦显示、不遮挡触发元素、Esc 关闭）。仅主导航、主按钮、分段控件保留文字。

> 代价：可发现性下降，依赖 tooltip 与命令面板兜底；对应 AR-20 的"命令面板 100% 覆盖"仍是硬门禁。

### D4 终端软换行（语义）

终端网格默认开启**软换行（soft wrap）**：超过列宽的行在视觉上折行，**不产生水平滚动**，且**不改变字符内容、网格列数与复制结果**；提供开关。折行续行给极轻的视觉提示。终端网格仍按固定行高 1.25 渲染，块状光标与字符级选区不变。

### D5 Agent 跟随会话 + 跨会话作用域（细化 DC-03）

引入 **Agent Scope** 概念，Agent Session 与 PTY Session 的关系从"两个平行会话"明确为"**可提升作用域的上下文对象**"：

| 作用域 | 含义 | 写操作风险 |
| --- | --- | --- |
| **本会话（默认）** | Agent 绑定当前激活的 PTY Session，随 tab/pane 切换而跟随 | 按 AR-06 常规分级 |
| **本工作区（跨会话）** | 可读写同 Workspace 内多个会话，引用需标注来源会话 | **风险上调一档**（L1→L2、L2→L3），必须逐次审批 |
| **多选会话** | 用户显式勾选参与会话 | 同上，且审批卡必须列出全部目标会话并要求二次输入目标名 |

硬约束：跨会话引用默认**只读**；跨会话写操作**不得**被规则固化（不可 session/rule 白名单）；审计必须记录'操作者=Agent、作用域、目标会话集合'。

### D6 减少滚动条

全局 overlay 滚动条（静止不可见/极淡、hover 显现、宽 6px、无轨道、不挤压内容）；终端靠软换行消除横向滚动；AI 面板长内容改为**可折叠分区**（默认展开 ≤2 个）；工作区视图首屏无页面级纵向滚动。

### D7 左侧导航与产品主对象的映射

参照物以 Host/Keychain/Proxies 为主导航，与我们的信息架构不符。收敛为：**Workspaces / Sessions / Snippets / Themes / Plugins / Audit Log + Settings**；主机、凭据、Known Hosts 降级为 **Workspace 内的资源视图**，不占主导航。

## 理由

- 发起人是产品所有者，其审美判断即为最终产品决策；ADR 的职责是把"好看"翻译成**可执行、可 CI 校验**的数值与规则。
- D3/D6 直接提升可用容积（把文字换成 tooltip、把滚动换成折行与折叠），D2 降低视觉噪声，三者共同解决"太挤"。
- D5 把"Agent 跟随会话"落成一个有权限语义的作用域模型，避免"Agent 读错会话/写错主机"这类高风险误操作。

## 后果

**正面**：视觉一致性可 CI 校验（单一标尺 + 单一按钮层级 + 零 emoji 图标）；浅色主题成为一等公民；信息容积提升；Agent 跨会话能力有明确的安全边界。

**负面 / 必须接受的代价**：

- 图标化牺牲可发现性，新用户学习成本上升（由 tooltip + ⌘K 面板 + 渐进披露补偿）。
- 软换行会使"超长单行日志"在视觉上占用更多行，降低单屏信息量（因此必须提供开关）。
- 跨会话 Agent 显著扩大攻击面：一次越权写入可能同时影响多个生产主机 → 必须配合 ADR-0015 的能力令牌与审计链。
- **docs/spec/02 需整体重写**（token 七组的值与视觉语言章节），且 DC-10 被取代；token codegen 管线（DC-09）不变，只是值变化。

## 反方记录与复议条件

- **反方（终端纯粹主义）**：macOS 浮动窗、卡片化、宽松留白会让"专业终端用户"觉得花哨、浪费屏幕。**保留意见**：若 dogfood 数据显示同等任务平均耗时或会话数下降，则回购密度（可提供"紧凑模式"而非回退整体视觉）。
- **反方（可访问性）**：图标化 + tooltip 对屏幕阅读器不友好。**缓解**：图标按钮必须带 `aria-label`（与 tooltip 同源），Tab 可达；AR-20 的 a11y 门禁不放宽。
- **复议条件**：发起人可随时否决本 ADR；若否决，原型与规则一并废弃，保留 v1 视觉。

## 关联决策与实现位置

- 取代：DC-10；修订：docs/spec/02（视觉语言与交互）、docs/spec/05（对比度门禁仍 ≥4.5:1 不变）。
- 不动：AR-01/AR-03/AR-05/AR-06/AR-07/AR-14/AR-16/AR-20、ADR-0013/0014/0015。
- 实现：`tokens/*.json`（新增浅色为一等主题与 azure 色阶）、`web-shell` 组件库、Agent Scope 状态机（`termai-agent` + `shell-bridge`）。
