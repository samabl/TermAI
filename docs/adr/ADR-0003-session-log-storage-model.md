# ADR-0003：结构化上下文与 Session Log 存储模型

- 状态：Accepted
- 日期：2025-01-01
- 决策者：Orchestrator（综合 10 角色评审）
- 关联：AR-04、DC-23；DC-18、DC-20、DC-22、DC-30、DC-33；HARNESS §4.1、§5、§6.1

## 背景与问题
1. 分歧：06 质疑「结构化事件总线是否过度抽象伤性能」；04/05 担心热路径序列化开销；07 要求稳定 schema 才能做评测与回放。
2. 现状痛点：字符串拼接的会话上下文是**隐私与评测的坟墓**——无法裁剪、无法脱敏、无法回放、无法断言。
3. 约束：AI 需要 OSC 133/633 命令边界、退出码、cwd、耗时、时间戳；同时 §5 要求解析+渲染吞吐 ≥500MB/s、空闲 RSS ≤120MB，24h RSS 斜率 <1MB/h。
4. 长期目标（P1 退出标准）：**SQLite 索引必须能从 Log 完整重建**。

## 可选方案（至少 2 个，含被否决项）
| 方案 | 主张方 | 否决 / 采纳理由 |
| --- | --- | --- |
| A SQLite 作为唯一真相源 | 常规工程直觉 | 否决。模式迁移风险高、不可回放、二进制不透明；索引损坏将导致历史丢失 |
| B 结构化事件总线走 JSON/gRPC（含热路径） | 06 质疑的默认解法 | 否决。热路径序列化开销与 GC/分配不可接受，违反 §0.4 第 7 条 |
| C append-only Session Log（唯一真相）+ SQLite 派生索引（可重建）+ CAS 大对象 | Orchestrator | **采纳**（AR-04、DC-23） |

## 决策
1. **唯一真相 = append-only Session Log**：分段 + 校验和；格式版本 + 迁移器兼容 ≥2 个大版本（DC-23）。
2. **SQLite(WAL) 只作派生索引**，任何时刻可删除并从 Log 完整重建；索引不承担真值职责。
3. **大对象走内容寻址 CAS**（日志片段、diff、附件），索引只存哈希引用。
4. **进程内通信**走 trait 直连 + 二进制快照/delta；**跨进程**才走 termai-ipc（长度前缀 + 版本/能力协商）；**热路径禁用 JSON/gRPC**。
5. **结构化事件惰性生成**：无消费者时零开销；有消费者时按订阅裁剪（订阅粒度 = 事件类型 + Pane + 时间窗）。
6. **schema 归属**：由 termai-core 的 IDL 定义并版本化，内核与 agent 共同维护；破坏性变更走 capability 协商，兼容窗口 ≥2 个 minor。
7. 脱敏在**上下文构建器内**完成（正则 + 熵检测 + keychain 反向匹配），失败默认**拒绝发送**（DC-33）；secret 永不落 Log 的明文字段。

## 理由
1. append-only + 校验和使「可裁剪、可脱敏、可回放、可评测」同时成立，是 AI 能力的前提（AR-04 理由）。
2. SQLite 可重建把存储风险从「数据丢失」降级为「性能劣化」，允许索引损坏时自愈。
3. 惰性生成保证未启用 AI / 无插件时，结构化开销为零，与 AR-03「AI 关闭零开销」一致。
4. 与 DC-20（line-arena + style-run，默认 10k 行/10MB，冷行下沉磁盘）配合，内存上界可静态估算。

## 后果（正面 / 负面 / 需要接受的代价）
- 正面：可回放（CI 行为回放 ≥99.5%）；可断言最终网格与状态；隐私可审计；评测有稳定真值。
- 负面：写入路径与索引维护增加工程复杂度；需要迁移器与版本矩阵测试；Log 体积增长需保留策略。
- 需要接受的代价：
  1. 必须为 schema 变更支付 capability 协商与 ≥2 minor 兼容窗口的维护税。
  2. **完整原始输出 scrollback 持久默认关闭**（AR-13、OQ-04），需要持久时由用户显式开启（可加密）。
  3. 项目记忆（.termai/）默认本地可见可删，且**默认不提交 git**（DC-30、OQ-13）。

## 反方记录与复议条件
- **反方（06，保留原文）**：结构化事件总线的抽象层可能落到热路径，拖累吞吐；主张更少的中间层。
- **反方（04/05）**：任何在 PTY 读取循环内的序列化都会侵蚀 key-to-photon 预算。
- **复议触发条件**：若惰性生成 + 订阅裁剪实测下，解析+渲染吞吐 <500MB/s 或 key-to-photon P99 >16ms，则针对该路径重新分层（例如把该事件类型下沉为定长二进制记录或延后到空闲批处理）。
- 复议证据要求：§5 门禁基准报告 + 剖面数据，指定被侵蚀的具体事件类型与调用栈。
