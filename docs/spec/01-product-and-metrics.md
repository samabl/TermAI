## 1. 目的与范围

**目的**：把 HARNESS §1 的产品第一性转成可执行、可验收、可被对抗性解读的产品规格——定位与公理、用户与 JTBD、失败即死清单、MoSCoW 矩阵、竞争叙事、商业与许可落地、指标树与反作弊定义、Phase 级产品 Exit Criteria、AI 降级体验。

**范围内**：产品定义、优先级、指标与验收口径、商业边界、竞争叙事。
**范围外**（本文件不裁决）：UX 交互与信息架构细节（→ 02-ux）、设计 token 与视觉（→ 03）、内核/渲染/架构（→ 04）、AI/Agent 契约与 eval（→ 05-ai）、安全隐私合规控制（→ 06-security）、插件与生态治理（→ 07-ecosystem）、工程门禁实现（→ 08-engineering）。

**效力规则**：

1. 本文任何量化值若与 HARNESS §5（预算）或 §8（门禁）不一致，以 HARNESS 为准；本文只做**落地化**，不做**重定义**。
2. 本文新增的、HARNESS 未覆盖的数值一律标【本文定义】，并登记进 §7 OQ，标注影响面与必须决策阶段。
3. 禁止在本文内出现与 AR / DC / Anti-features 相反的产品结论；有异议只写入 §7。
4. 任何功能条目必须同时能回答三问：落在哪个 Phase（§7）、满足哪条 DC、受哪条预算/门禁约束——否则不得进入 MoSCoW 的 Must/Should。

## 3. 详细设计

### 3.1 定位与产品公理（冻结措辞）

> **TermAI 是一个把「从报错到修复」的全部上下文交给可审计 AI 的现代终端：终端模拟器 + 结构化上下文总线 + 内嵌 Agent + 插件生态。**

三条公理（A1 信任基础设施 / A2 本命是延迟、正确性、可脚本化 / A3 AI-native = 状态结构化）在本规格内的产品级推论：

1. 任何功能若在「AI 全关」时降低终端核心体验，按 P0 缺陷处理（A2 + AR-03）。
2. 任何 AI 能力的对外文案必须同时声明**审批级别、可撤销范围、数据出网情况**三项，不得只讲效果（A1 + AR-20 诚实原则）。
3. 「结构化」是产品承诺不是实现细节：命令块、退出码、cwd、耗时、Git/容器/文件系统状态必须可经 Local API 读取（A3 + DC-24）。

### 3.2 Persona 与 JTBD

| 层级 | Persona | JTBD | 核心痛点 | 付费与传播属性 |
| --- | --- | --- | --- | --- |
| **Primary** | SRE / 平台工程师 | 线上故障时快速定位并**安全**执行修复 | 上下文散落于 SSH / 日志 / K8s / 聊天记录；分不清生产与预发；无审计 | 付费意愿最强；团队内传播 |
| **Primary** | 高级软件工程师 | 在终端内闭环完成构建—调试—提交 | 命令历史不可检索；AI 读不懂报错；多仓库切换丢失上下文 | 口碑与插件供给 |
| Secondary | 数据 / AI 工程师 | 长任务、环境与 GPU 资源管理 | 会话丢失、环境不可复现 | 长任务场景带来差异化演示 |
| Secondary | CLI 重度用户 / 终端爱好者 | 管道、脚本、配置、主题、插件 | AI 干扰原始输出；配置不可编程 | 生态与主题供给 |
| **明确不做** | 零基础学习者 | — | — | AR-15：不做教学市场、不做欢迎向导 |

| **Kitty / Alacritty** | 性能基准线，非直接对手 | 实现 Kitty 协议与键盘协议兼容以承接迁移 |
| **iTerm2** | macOS 霸主 | 主攻挖角：AI 诊断 + 跨平台一致体验 + 可审计 |
| **Tabby** | 证明可扩展终端有需求，但 Electron 重 | 以原生性能与内存预算（≤120MB / 10 tab）收割 |
| **Wave** | **反面教材**：重 GUI、偏教学 | 反向约束：不做 Web 应用化、不做教学（AR-15、Anti-feature 4） |
| **Fig / Amazon Q** | 补全引擎，能力互补 | 可集成但**不依赖其云端**；补全不是护城河（AR-17） |
| **Cursor 终端** | 不与之争 IDE 内终端 | 反向通过 CLI/MCP 成为其**外部终端后端**（分发策略，DC-28） |
| **tmux / zellij** | 共存优先 | 键位与控制模式兼容，内置替代但**不强制**（AR-13）；诚实声明「屏幕可恢复，进程不可恢复」 |

**差异化叙事（对外三句，不可扩写）**：

1. **可审计的写回**：AI 只能产出结构化意图，命令由确定性执行器构造，每个动作有风险级别、审批人、审计链与撤销边界（AR-06 / 黄金规则 1、4、7）。
2. **结构化上下文**：命令块、退出码、cwd、Git/容器状态是 AI 可读对象而非字符串拼接（A3 / AR-04）。
3. **本地优先且可离网**：BYO-Key 直连、遥测默认关、云端不落内容、无外网时功能完整（AR-11 / AR-12 / P4）。

**明确不参与的战场**：默认终端之争、IDE 内终端、教学市场、模型能力军备竞赛、插件市场抽成。

### 3.6 商业模式与许可落地形态（依据 AR-21 / ADR-0013）

| 层级 | 内容 | 免费边界 | 许可与开源形态 |
| --- | --- | --- | --- |
| **Free** | 本地全功能终端 + BYO-Key AI + 基础插件运行 | 本地能力**永不被远程锁死**；无功能降级计时器 | **Apache-2.0 OR MIT**（客户端全栈开源，OQ-01 已关闭）(ADR-0013) |
| **Pro** | 托管 AI 额度通道（经我方转发并 UI 明示）、同步（CRDT 小文档）、高级插件能力 | 托管额度不可用时自动回落 BYO-Key | 服务端同样开源（**Apache-2.0 OR MIT**）；售卖形态 = 托管服务，非源码封闭 (ADR-0013) |
| **Team** | 团队共享配置与方案模板、共享策略、审计汇总 | 策略只能加强不可削弱（DC-35） | 全栈开源（**Apache-2.0 OR MIT**）+ 支持订阅 (ADR-0013) |
| **Enterprise** | SSO/SCIM、SIEM 审计导出、私有模型网关、私有插件 registry、离线部署、自托管控制面（OQ-17） | 无外网部署功能完整（P4 门禁） | 全栈开源（**Apache-2.0 OR MIT**）+ 合规/企业服务合同；企业专有定制只能作独立插件或独立仓库，**不得回流核心** (ADR-0013) |

落地硬约束：

1. **全栈开源、统一 Apache-2.0 OR MIT**（客户端 + 服务端 + SDK + 协议 + 工具链，CI 校验 SPDX 表达式）；**不存在闭源云端模块**；企业专有定制不得回流核心；**不采用 BSL / SSPL**；不因许可变更追溯已发布版本（变更需 TSC 2/3 + 90 天公示，R12）(ADR-0013)。
2. **插件公共市场 v1 零抽成、无 DRM**；收入来自企业私有 registry、Verified 认证与合规能力；抽成政策变更需 TSC 决议 + 90 天公示、不得追溯已发布插件（OQ-14）。
3. **主题格式与主题商店永久免费开放**（DC-12）。
4. **永不出售或训练用户数据**；服务端 prompt/completion 字段 = 0（AR-11 + §8.2 隐私门禁，AR-21 不改变该边界）。
5. 计费**只认托管通道**；BYO-Key 直连不得被计量或限速。
6. 许可一致性：核心链接边界禁 GPL/AGPL/SSPL，弱 copyleft（MPL-2.0/EPL-2.0）准入与「链接边界」的可执行定义由 ADR-0015 给出；许可与开源范围变更需 TSC 2/3 + 90 天公示（AR-21 / ADR-0013）。

### 3.7 指标树（NSM + 护栏 + 先导 + 反作弊定义）

**树形关系**：入场券指标（性能/兼容）→ 信任护栏（安全/隐私）→ 先导指标（AI 有用性）→ **NSM**（Accepted AI Actions per WAU）→ 留存（D7/W4）→ 商业转化。

| 层 | 指标 | 口径（operational definition） | 目标 | 出处 |
| --- | --- | --- | --- | --- |
| **NSM** | Accepted AI Actions per WAU | 每自然周，被用户显式接受且产生**可观察状态变化或显式请求产出**的 AI 动作数 ÷ 该周 WAU | ≥ 5（上线 6 个月） | §1.4、DC-07 |
| 先导 | AI 建议接受率 | 接受的建议数 ÷ 展示的建议数（去重后） | 25%–40% | §1.4 |
| 先导 | 故障诊断闭环率 | 诊断卡片被采纳并执行后续动作的比例 | 【本文定义】待 OQ-P-02 确认 | AR-17 |
| 先导 | ?? 内联入口使用率 | 用过内联入口的 WAU ÷ WAU | 【本文定义】先观察不设阈值 | AR-16 |
| 护栏 | 危险命令误执行率 | 未预期破坏性副作用次数 ÷ 展示的危险命令总数 | < 0.5% | §1.4 |
| 护栏 | L2/L3 未审批执行次数 | 无审批即执行的 L2/L3 动作计数 | **= 0** | §1.4、§8.2 |
| 护栏 | AI 关闭时终端核心可用性 | 以关闭 AI 的 Launch flag 运行基础回归 | **100%** | §1.4 |
| 护栏 | 盲确认率 | 确认弹窗出现后 5 秒内直接确认的比例 | < 15% | §8.2 |
| 护栏 | 出网 secret 泄露事件 | 出站请求命中凭据库/熵检测的次数 | 0 | §1.4、§6.3 |
| 护栏 | 遥测关闭时上传字节 | 关闭态下出站遥测字节数 | 0 | §8.2 |
| 护栏 | 有监督 UI 回看覆盖率 | 出网请求可在 UI 回溯的比例 | 100% | §8.2 |
| 入场券 | key-to-photon（本地） | 按键到像素 P99 | ≤16ms【门禁】/ ≤8ms【目标】 | §5、AR-19 |
| 入场券 | 冷启动到可输入 | P95（release，SSD） | ≤150ms【门禁】/ ≤100ms【目标】 | §5、AR-19 |
| 入场券 | 空闲 RSS（1 万行） | 进程采样 | ≤120MB【门禁】 | §5 |
| 入场券 | 安装包体积 | 产物度量 | <60MB【门禁】 | §5 |
| 留存 | D7 / W4 | 自然周回访口径 | ≥40% / ≥20% | §1.4 |
| 可靠性 | crash-free session | 无崩溃会话占比 | >99.9% | §8.2 |
| 商业 | 控制面单 MAU 成本 | 云成本 ÷ MAU | ≤ $0.05/月 | §5 |
| 商业 | 托管通道付费转化 | 【本文定义】付费席位 ÷ opt-in 面板口径 WAU | OQ-P-04 后设定 | AR-21 |

**反作弊 / 反造假定义（NSM 与先导指标通用）**：

| # | 规则 |
| --- | --- |
| G1 | 计入的动作必须是**状态变更类**（写文件/改仓库/改配置/执行命令）或**用户显式请求的解释/诊断产出**；UI 展示、动画、心跳、重复渲染一律不计 |
| G2 | 去重键 = 归一化意图哈希（tool + argv + 目标路径/主机）；同一动作 60 秒内重复只计 1 次 |
| G3 | 分母 WAU = 一周内至少产生一条**带 exit code 的完整命令块**的安装实例；禁止用「启动即计数」或纯面板打开扩充分母（OQ-P-03） |
| G4 | **未审批的自动执行不计入 Accepted**；且该行为本身违反 AR-06，属事故不计入指标 |
| G5 | 禁止为指标在产品内设置诱导路径（未经请求主动弹出的 AI 建议、默认开启的整行预测）；整行灰字预测默认关闭（AR-16） |
| G6 | 指标口径变更须同时更新本文与 dashboard 版本号，并对 ≥90 天历史重算；**禁止只改分子不改分母** |
| G7 | 任何以「提升接受率」为由放宽风险规则或降低 L2/L3 摩擦的 PR 一律拒绝；危险命令率上升即阻断合入（DC-31） |
| G8 | 遥测关闭的用户不进入云端聚合，仅本地可见；任何对外报告必须写明口径覆盖（opt-in 面板 ≠ 全量），禁止把面板样本表述为全量（AR-12、OQ-P-01） |

| Phase | 产品级 Exit Criteria（全部满足才可进入下一 Phase） |

### 3.9 AI 功能的「降级体验」定义

总原则：**降级只减少「AI 增值」，绝不减少「终端本命」**（A2 + AR-03）。任何降级路径必须可在无网络、无账号、无 Key、无 WebView 的环境下走完。

| 降级触发 | 产品行为 | 禁止行为 | 锚定 |
| --- | --- | --- | --- |
| AI 进程崩溃 / 被 watchdog 终止 | 终端零阻塞；面板显示「AI 不可用」+ 重试；内联入口置灰并说明原因 | 阻塞输入、弹模态、影响 PTY 会话 | AR-03、DC-38 类比 |
| 用户关闭 AI（Launch flag / 设置） | 冷启动无 AI 开销；命令面板隐藏 AI 动作但功能覆盖率仍 100%（CI 在关闭配置下运行） | 后台拉起 AI 进程、发送任何网络请求 | AR-03、§8.2 |
| 无网络 / 离线 | 仅本地规则解释 + 本地检索；UI 明示「离线模式：仅规则解释」 | 生成诊断结论（幻觉） | DC-29 |
| 未配置 BYO-Key | 命令面板内一次性入口引导；本地能力全部保留 | 弹窗式欢迎向导（Anti-feature 12） | AR-15 |
| 托管额度耗尽 / 网关不可用 | 提示并可回落 BYO-Key 直连 | 锁死本地功能 | AR-21、AR-11 |
| WebView 缺失 / 不可信 | 降级为**纯原生文本面板**，AI 以文本形态可用 | 因 WebView 缺失导致产品不可启动 | AR-02、OQ-02 |
| 模型输出触发策略拒绝 | 明确原因 + 写入审计条目 + 提供替代路径 | 静默失败 | DC-35、DC-34 |
| 脱敏失败 | **拒绝发送**并告知用户哪类内容被判定为敏感 | 为保「AI 可用」而放行 | DC-33 |
| AI 首 token 超时（P95 >3s 目标） | 降级为本地规则解释并标注 | 无限等待、吞掉用户输入 | §5、DC-29 |
